# claude-tools

Утилиты для рабочих процессов с Claude (claude.ai).

## injection_guard.py

Детектор скрытых prompt-injection закладок в документах: скрытый и белый текст,
микрокегль, колонтитулы и метаданные в DOCX, невидимый текстовый слой в PDF,
невидимые Unicode-символы (zero-width, Unicode Tags), лексика с императивами,
адресованными ИИ.

Запуск:

```
python3 injection_guard.py файл.docx [--clean]
```

Флаг `--clean` дополнительно выгружает извлечённый текстовый слой в `файл.clean.txt`.

Коды возврата: `0` чисто, `1` найдены подозрительные фрагменты, `2` ошибка.

Зависимости: для DOCX достаточно чистого Python 3, для PDF нужны внешние утилиты
`pdftotext` (пакет poppler-utils) и `qpdf`.
